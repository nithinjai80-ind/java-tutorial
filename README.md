## 🚀 Prerequisites

Before running the programs, install:

- Java JDK 17 or later
- Visual Studio Code / IntelliJ IDEA / Eclipse
- Git (Optional)

Check Java installation:

```bash
java --version
```

Check Java compiler:

```bash
javac --version
```

---

## ▶️ How to Run

### Clone the Repository

```bash
git clone https://github.com/nithinjai80-ind/Java-Tutorial.git
```

### Navigate to the Project

```bash
cd Java-Tutorial
```

### Compile a Java Program

```bash
javac HelloWorld.java
```

### Run the Program

```bash
java HelloWorld
```
